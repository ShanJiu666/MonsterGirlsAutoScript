# 使用说明书（照做就行，一共 4 步）

> ⭐ 这份是**发给朋友的成品说明书**（`tools\build_pkg.py` 打包时会把它拷成包根的
> `使用说明书.md`）。改文案就改这里，**别只改包目录里那份** —— 包目录每次重打包都会重建。

## 一次性准备
1. 装 **MuMu 模拟器**（12 或更高），在里面装好**幻想少女公会**并登录账号。
2. 把模拟器**分辨率调成 720×1280（竖屏）**：
   MuMu 右上角「设置」→ 显示 → 分辨率 → 自定义 720×1280。
   （不设的话，启动时会弹窗提示并**拒绝启动**，按提示改好再启动即可。）

## 每次使用
3. 打开游戏，**停在「选图界面」**（能看到「进入地图 / 快速扫荡」那个界面）。
4. 解压整个文件夹，双击 **`启动.bat`** → 弹出操作窗口 → 点 **▶ 开跑**。

## 窗口上那几个勾选（主控制卡右侧）
从左到右：**公会日常 ｜ 免费招募 ｜ 免广告 ｜ 自动补给 ｜ 每 N 张图升星 ｜ 存图**
（都紧挨着「■ 停止」右边，一眼都看得见。）
⭐ 「**立即招募**」按钮已挪到「**工具**」页签（在那一排按钮的最后）。

- **公会日常**（一颗 = 三件事）：体力刷完后，自动去公会**一次做完**：
  - **派遣任务**：把 4 把小队的任务都派出去，顺便领掉已完成的奖励。
    花的是**时间**，不花体力/金币 —— 纯收益，建议勾上 ✓
    （**不会**放弃任务、**不会**召回队伍。）
  - **情报领奖**：点公会右上角「情报」，**每日情报**逐条领、
    **每周情报**领最上面那条 —— **纯领奖、零消耗**（不花体力/金币/宝石）✓
    （**不会**点「购买情报指南」，那要花宝石。）
  - **炼金**：去顶楼点炼金宝箱 → 点「**满星**」→ 点「**开始炼金**」。
    ⚠⚠ **会消耗 6 件 5★ 满星装备**（换成金币 + 结晶，**不可逆**）⇒ 想清楚再勾。

- **免广告**（默认勾上）：勾上 ⇒ 体力刷完后自动**看广告领奖**：
  **购买体力×3 ｜ 四叶草×3 ｜ 金币×3 ｜ 加速炼金×1**。
  - ⚠ 这个勾选的真正含义是「**这个号有免广告权益**」（= 月卡里那条「免广告」）。
  - **不勾 ⇒ 这四个入口一下都不碰** —— 因为没有免广就得真播视频广告，脚本做不了。
  - 全程**不花宝石**（只点"看广告"那颗绿按钮，**不点**花宝石那颗）。
  - 每日次数以游戏里显示的 `剩余/上限` 为准，领完自动停 ✓

- **免费招募**：勾上 ⇒ 体力刷完后自动做**免费指定招募**（算「**保底最高**」的标签组合，
  抄小助手那套权重算法）⇒ **尽量拿到高等级角色**。
  - 想**立刻**抽一次：去「**工具**」页签点「**立即招募**」（需先勾上这颗）。
  - ⚠ 只在**那颗按钮还亮着**（今天免费机会没用）时才做；用掉了会**自动跳过**（**不花宝石** ✓）。

- 勾了会记住（**按模拟器分别记**，换个窗口各自一份）。

## 天赋果实记录（「工具」页签）
⭐ **全自动**：收工时**体力低于 100** 时，会自己去**背包 → 道具**扫一次天赋果实数量并记录。
（放在日常/招募/广告**之后**扫，那时记的才是"今天的最终状态"。）

**怎么看**：去「**工具**」页签，点「**果实记录**」⇒ 记录**直接显示在下面那个框里**
（不用去日志页找）。显示这些：

| 项 | 含义 |
|---|---|
| 累计获取 | 一共拿到多少（**首日只当基准，不算**）|
| 累计消耗 | 一共用掉多少 |
| 净变化 | 获取 − 消耗 |
| 每天平均 | 按有效天数跨度摊平 |
| 日增峰值 | 单次最多的那一天 |

- **「边收边用」也认得出来**：今天涨了 5 个、同时用掉 3 个 ⇒ 算成**获得 8 个**。
- **同一天扫多次只算一天**（取当天最后一次的数量，不会当成多天）。

记录文件在 `runs/<实例名>/fruit_record.json` —— **每个窗口独立**，换个模拟器各记各的。
（纯文本 JSON，你想手动改也行。）

## 出问题怎么办
- 先点窗口上的 **■ 停止**，然后把这两个文件发我：
  - `mapbot_pc\runs\gui_*.log`（最新那个）
  - `mapbot_pc\runs\loop\loop_log.json`
- 有截图更好（模拟器窗口截一张）。

## 更新（**你什么都不用做**）
- 双击 `启动.bat` 时程序会**自己查有没有新版本**（走网络，几秒；没网就跳过），
  有的话悄悄下载，**下次打开就生效** —— 不用重下压缩包、不用管。
- 万一新版本有问题：程序**自己会退回**上一个能用的版本（连续两次起不来就自动回滚），
  坏版本留在 `mapbot_pc\hot\bad\` 里。
- 想看我这边收到了什么：`mapbot_pc\runs\updater.log`
  （最新的几行会写「已就绪 / 自检通过 / 已回滚」）。

## 常见问题
- **双击完全没反应 / 窗口一闪就退**：先看 `mapbot_pc\runs\bootstrap_error.log`
  （有的话一并发我）；没有这个文件，多半是没解压完整（要整个文件夹一起解压，别只拖 `启动.bat` 出来）。
- **首次双击被 Windows SmartScreen 拦**：点「更多信息 → 仍要运行」即可（未签名程序的正常提示）。
- **认不到模拟器**：先手动打开 MuMu，等它完全进桌面再点 ▶。
- **提示分辨率不对**：按弹窗说的把模拟器改成 720×1280 再启动。
- **不动/乱点**：分辨率不是 720×1280，或游戏没停在选图界面。
- **很慢**：本包已带「快速截图服务」；若它没起来会自动退化成慢速（能用但慢约 15%）。
