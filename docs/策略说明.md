# 探索策略说明

> 目标函数：**消耗体力最少**。
> 验证方式：离线生成大量开局盘，与 Dijkstra 理论最优解对比（毫秒级，不需要真机）。

---

## 一、体力规则

一次探索里，每一步的体力消耗只跟**点的那个地块**有关：

| 动作 | 体力消耗 |
|---|---|
| 点空地 / 普通地块 | 该地块的格数（1 格地块 = **1**） |
| 点战斗格 | 格数 × 2（1 格地块 = **2**） |
| 点探索产出格 | 格数 × 2 |
| 进图（固定） | 25 |
| 放弃探索 | 5 |

⇒ **多格大地块很贵**：一个 2×2 的首领块点一下就是 **8 点**，等于 8 格空地。

---

## 二、地图机制

| 机制 | 规则 |
|---|---|
| 点空地 | 触发**连通消除**：与它四邻接连通的整片空地一起被消耗 |
| 点非空地 | 只消耗这一块，并弹出对应面板（战斗 / 商人 / 宝库 / 宝箱…） |
| 揭示 | 某个地块被消耗后，与它四邻接的格变为**已揭示**（此后可点） |
| 开局可见 | 营地 + 它周围一圈 |
| 未揭示格 | 画面更暗、**点不动**，但它的**标记仍然画得出来** —— 所以会出现「看得见却打不了的首领」 |

> 「连通消除」是这套策略的核心：点一格空地可能顺手消掉一整片，
> 因此**点大片空地往往比点单格更划算**。

---

## 三、策略（机器人照着执行，无搜索、无 AI）

1. **目标集合** = 带标记的格 ∪ 旅行商人 ∪ 黄金宝库
   - 标记：首领 / 红装 / 大拇指（推荐） / 幸运草
   - 其他已揭示的内容格（木箱 / 宝箱 / 海螺 / 游乐设施 / 勇者之墓…）**不是目标**
2. **红装硬停**：只在**刚进图那一次扫描**里判红装（之后不判，避免面板里的同类图标误判）
   ⇒ 一旦发现就**停止、不退图、上锁**，留给人工处理
3. **能点的目标直接点**（不受成本上限约束）；点了商人 / 宝库就把面板走完
4. **目标点不动时**，沿「营地 → 目标」的**直线**点可点的格来开路
   - 直线取格用 Bresenham
   - **便宜优先**：开路格按体力成本排序（1 格空地 1 体 ≫ 优先于 4~8 体的大块内容格）
   - 直线上没有可点的格时，用「走廊」判据兜底：
     `|d(营地,格) + d(格,目标) − d(营地,目标)| ≤ 2`
5. **点序交替**：揭一格 → 试一次目标 → 再揭一格（不连着揭好几格才试目标）
6. **无关战斗不打**：只有「落在开路线上的战斗格」或「紧挨目标的战斗格」才打；
   其余内容格弹出来的战斗面板直接关掉
7. **特殊面板**：偶遇 / 遭遇强敌 → 不打，点右上角关闭；发现莱姆 → 点返回
8. **目标清完立刻退图**：退图前只补点**一下**（点最近点过的那格）
9. **摇色子**：带「大拇指」标记的战斗结束后可重摇（最多 3 次）
   - 判定「奖励行出现大拇指装备」用**形状 + 配色双判**（阈值 0.70；真标记 0.92+、噪声 ≤ 0.55）
   - 判定前必须**等奖励行稳定**（连续 2 帧几乎不变），否则会在动画中途误判
10. **不拉黑**：标记格 / 商人 / 宝库永不拉黑（点两次没反应也继续当目标）

## 四、离线实测

```powershell
python strategy.py --bench 150 --map 夏日海滩 --difficulty 100
```

| 策略 | 平均体力 | 相对最优 | 漏目标 |
|---|---|---|---|
| **理论最优（Dijkstra）** | **7.82** | — | 0 |
| **现行规则（本文第三节）** | **10.36** | +32.5% | 1/150 |
| 现行 + 便宜优先（第 4 条已含） | 10.25 | +31.0% | 1/150 |
| 纯贪心打分（试验） | 20.28 | +159% | 91/150 |
| 直线成本重写（试验） | 20.35 | +160% | 91/150 |

**结论**：

- 这套骨架**已接近最优**（差 31%），而两次「重写」都差得多 ⇒ **不要重写骨架**
- 「便宜优先」确实有效但收益小（1.5%），因为直线上本来就多是 1 格空地
- 剩余差距主要来自「必须穿过大块内容格」和「直线路线不是唯一解」的情形

## 五、可继续优化的方向

1. **运行时用一次 Dijkstra**（`--opt` 开关，已接进 `explore_loop`）：可以做到「每步都最优」
   - ⚠ 一次性给出多步计划时若含未揭示格，真机执行会点不动
     ⇒ 需改成**只取第 1 步、下一轮重算**才可用
2. **多地图 / 多难度验证**：目前只跑了夏日海滩 / 难度 100；换 `--map` / `--difficulty` 即可
3. **用真实盘校准生成器**：攒 20~50 张真实盘对比地块数与特殊格占比，
   把 `mapgen.py` 调得更接近服务端

## 六、怎么复验（不需要真机）

```powershell
python mapgen.py  --maps 3 --map 夏日海滩 --difficulty 100       # 看生成的盘
python strategy.py --bench 150 --map 夏日海滩 --difficulty 100   # 与最优解对比
python mapsolve.py --show 3 --map 夏日海滩 --difficulty 100      # 看最优解长什么样
python mapsim.py  --sample runs/some_frame.png                   # 用一张截图建盘跑一遍
```
