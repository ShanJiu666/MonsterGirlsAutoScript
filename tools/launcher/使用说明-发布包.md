# 幻想少女公会 · 自动探索（PC 版）

> **下载解压 → 双击 `MGAS.exe` → 开跑。**
> 不需要装 Python、不需要装任何依赖、不需要命令行。

---

## 一、三步开始

### 1. 解压

把下载的 `MGAS-v1.0-portable.zip` **完整解压**到任意目录（建议**不要**放在中文路径或桌面）。

> ⚠ **一定要等解压真正走完再双击。**
> 压缩包解开要一两分钟（近 3 万个文件），中途双击会出现
> 「包不完整：缺少 python311\Lib\tkinter\...」之类的提示 ——
> 那不是软件坏了，是**文件还没解压出来**。
>
> 启动器会先做完整性自检，缺什么会**直接告诉你缺哪个文件**。
> 看到那句提示 ⇒ 等解压完 / 重新解压一次即可。

> ⚠ **别只挑一部分文件出来**，也别在压缩包的预览窗口里直接双击运行。

### 2. 准备模拟器

1. 装 **MuMu 模拟器 12**（Android 12 或更高），在里面装好游戏并**登录**
2. 把模拟器分辨率设成 **720 × 1280**（本工具只认这个基准）
3. 让游戏停在**选图界面**或**地图里**都行

### 3. 双击 `MGAS.exe`

出现窗口 → 选设备 → 勾选想要的目标 → 点「开始」。

如果 `MGAS.exe` 被杀毒软件拦了，改双击 **`幻想少女公会-自动探索.bat`**（效果一样，只是会带一个黑框）。

## 三、常见问题

**双击没反应 / 一闪就没了**

看 `logs\launcher.log`，末尾会写清原因。最常见两种：
- **杀毒软件拦截** → 把整个文件夹加入白名单
- **包不完整** → 重新完整解压一次

**提示「找不到 Python 运行环境」**

说明 `python311\` 目录丢了 —— 重新解压整个包。

**提示「包不完整：找不到 bot_gui.py」**

只解压了一部分文件。请解压**整个** zip。

**连不上模拟器**

1. 确认 MuMu 已经启动、游戏已登录
2. 用 MuMu 自带的 `adb.exe` 试一下：
   ```
   "C:\Program Files\Netease\MuMuPlayer-12.0\shell\adb.exe" connect 127.0.0.1:16384
   ```
3. 端口不是 16384 的话，在启动器里换设备号（或者设环境变量 `MAPBOT_DEV`）

**跑图很慢**

OCR 是主要瓶颈。我试过把固定 UI 全改成模板匹配（比 OCR 快 400 倍以上），
剩下的 OCR 只用于确实会变的内容（体力数字、倒计时、图名、价格）。

**想改目标 / 看统计**

界面上「目标」那几个勾选框就是。日志在 `runs\` 目录。

## 四、目录里都是什么

```
MGAS.exe                     ← 双击这个
幻想少女公会-自动探索.bat      ← 备用启动（exe 被拦时用）
python311\                   ← 内嵌 Python（别删）
venv\                        ← 内嵌依赖（别删）
bot_gui.py                   ← 界面
explore_loop.py              ← 主流程
spots.py / marks.py          ← 识别
mapsim.py / mapsolve.py      ← 规划
templates\                   ← 识别模板（别删）
data\                        ← 游戏数据表（别删）
docs\                        ← 说明书 / 算法 / 策略
tests\ / devtools\           ← 回归测试 / 排障脚本（普通使用用不到）
runs\                        ← 运行日志与截图（自动生成）
```

## 五、卸载
